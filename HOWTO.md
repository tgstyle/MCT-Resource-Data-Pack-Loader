# Resource Data Pack Loader

**One folder that overrides anything Minecraft or a mod provides, defines new content from JSON, and controls what generates, in every world, on clients and servers, with nothing for players to switch on.**

**Одна папка. Переопределяет всё, что даёт Minecraft или мод, описывает новый контент в JSON и управляет генерацией мира — в любом мире, на клиенте и на сервере, и игроку ничего включать не надо.**

**Ein Ordner. Überschreibt alles, was Minecraft oder ein Mod mitbringt, beschreibt neuen Inhalt in JSON und steuert die Weltgenerierung – in jeder Welt, auf Client und Server, und der Spieler muss nichts einschalten.**

Each Minecraft version has its own guide: 1.12.2, 1.20.1 and 1.21.1. The 1.20.1 and 1.21.1 builds read the same packs. Anything below that applies to only some versions starts with those versions.

Для каждой версии Minecraft есть своё руководство: 1.12.2, 1.20.1 и 1.21.1. Сборки 1.20.1 и 1.21.1 читают одни и те же паки. Всё, что ниже относится не ко всем версиям, начинается с номеров этих версий.

Für jede Minecraft-Version gibt es ein eigenes Handbuch: 1.12.2, 1.20.1 und 1.21.1. Die Builds für 1.20.1 und 1.21.1 lesen dieselben Packs. Was unten nur für einige Versionen gilt, beginnt mit diesen Versionen.

## Adding a language · Добавить язык · Sprache hinzufügen

Copy `howto_localized/HOWTO-en_us.md` to `howto_localized/HOWTO-<code>.md` on each version's branch, translate the prose, and add a row to the table above. Leave every JSON block, key name, folder name and command exactly as it is: those are what a pack author types.

Скопируйте `howto_localized/HOWTO-en_us.md` в `howto_localized/HOWTO-<код>.md` в ветке каждой версии, переведите текст и добавьте строку в таблицу выше. Все блоки JSON, имена ключей, имена папок и команды оставьте как есть: именно их набирает автор пака.

Kopiere `howto_localized/HOWTO-en_us.md` im Branch jeder Version nach `howto_localized/HOWTO-<code>.md`, übersetze den Text und füge der Tabelle oben eine Zeile hinzu. Alle JSON-Blöcke, Schlüsselnamen, Ordnernamen und Befehle bleiben genau so, wie sie sind: Genau die tippt ein Pack-Autor.
